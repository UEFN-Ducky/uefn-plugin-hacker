# Hacker

Matrix-green terminal theme with fullscreen rain effect. Appearance + Matrix FX in one plugin.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`hacker`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/hacker-1.0.8.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
